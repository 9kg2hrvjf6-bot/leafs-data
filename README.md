LED Ticker is a smart, Wi‑Fi‑connected sports display that brings real‑time scores, schedules, and game updates to your desk, shelf, or entertainment setup. Powered by an ESP32 microcontroller and a vibrant RGB LED matrix, it delivers smooth animations, crisp text, and customizable team tracking — all without requiring any paid sports API.

Designed for fans who want a clean, modern way to follow their favorite teams, SportPulse uses an open data feed and your own cloud‑generated JSON scoreboard to keep updates fast, reliable, and commercial‑safe.

🎯 Key Features
Live Scores & Game Status  
Displays real‑time updates for hockey, baseball, basketball, football, and more.

Wi‑Fi Connected  
Automatically fetches your JSON scoreboard feed from GitHub Actions or any custom endpoint.

Ultra‑Bright RGB LED Matrix  
Smooth scrolling text, animations, and color‑coded team indicators.

Customizable Teams  
Track any team by name — no logos or trademarks required.

Smart Modes

Game Day Mode

Standings Mode

Next Game Countdown

Breaking Score Alerts

Compact & Modern  
Fits perfectly on a desk, shelf, or media center.

Open Firmware  
Your firmware is original, commercial‑safe, and easy to update.

📐 Technical Specifications
Microcontroller: ESP32 (dual‑core, Wi‑Fi enabled)
Display: HUB75 or NeoMatrix RGB LED panel
Resolution: 32×64 or 64×64 (configurable)
Power: 5V USB‑C or barrel jack
Connectivity: 2.4 GHz Wi‑Fi
Firmware: Custom C++/Arduino code
Data Source: JSON feed (GitHub Actions recommended)
Mounting: Desktop stand or wall mount
Case: 3D‑printed or injection‑molded (your choice)

This product displays publicly available sports information using text‑only data. It does not include or distribute any team logos, trademarks, or proprietary sports content. All hardware, firmware, and design elements are original and owned by the creator.
